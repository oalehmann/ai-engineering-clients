# Clientes Asíncronos de Python para OpenAI y Anthropic

## Descripción del proyecto

Este proyecto implementa clientes asíncronos en Python para interactuar con modelos de lenguaje de OpenAI y Anthropic.

El objetivo es desarrollar una estructura sencilla y reutilizable que permita enviar solicitudes a modelos de lenguaje y recibir respuestas, incluyendo respuestas en streaming.

## Funcionalidades previstas

* Cliente asíncrono para OpenAI.
* Cliente asíncrono para Anthropic.
* Validación de datos mediante Pydantic.
* Soporte para respuestas estándar y respuestas en streaming.
* Configuración mediante variables de entorno para las claves de API.

## Tecnologías utilizadas

* Python
* API de OpenAI
* API de Anthropic
* Pydantic
* Programación asíncrona

## Estado del proyecto

Configuración inicial del proyecto. La implementación de los clientes y las instrucciones de instalación, configuración y uso se incorporarán a medida que avance el desarrollo.
